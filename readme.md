# Thoughts and Observations
A reconstruction of "Thoughts and Observations" by my maternal grandfather.

## OCR
I wrote [this OCR program](https://github.com/TimHanewich/thoughts-and-observations/releases/download/1/TAO.zip) to use an LLM hosted in Microsoft Foundry to recognize and transcribe the text in images captured of the physical "Thoughts and Observations" book.
